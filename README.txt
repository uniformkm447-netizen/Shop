ПРАКТИЧЕСКАЯ РАБОТА №5 — МАГАЗИН КОМПЬЮТЕРНОЙ ТЕХНИКИ

ЭТОТ АРХИВ ПЕРЕСОБРАН С КОРОТКИМИ ИМЕНАМИ ПАПОК И ФАЙЛОВ.
Распакуйте его прямо в C:\Shop5 (создайте такую папку заранее).
После распаковки откройте C:\Shop5\Shop.sln.

СТРУКТУРА:
  Shop.sln       — решение Visual Studio (обычный формат .sln)
  Api\Api.csproj — Web API магазина
  Desk\Desk.csproj — Windows Forms клиент

ЗАПУСК:
1. Откройте Shop.sln в Visual Studio.
2. Восстановите NuGet-пакеты, если Visual Studio попросит.
3. В свойствах решения выберите «Несколько запускаемых проектов».
4. Для ComputerStoreApi и ComputerStoreDesk задайте действие «Запуск».
5. Убедитесь, что API запускается на http://localhost:5101.
   Swagger: http://localhost:5101/swagger
6. Нажмите F5. Сначала запускается API, затем открывается окно каталога.
7. В окне нажмите «Загрузить».

ВАЖНО:
- Для сборки необходим .NET 10 SDK и рабочая нагрузка «Разработка классических приложений .NET».
- Если HTTP-порт API отличается от 5101, поменяйте BaseAddress в начале Desk\Form1.cs.
- Кнопка «Эксперимент: .Result» намеренно демонстрирует зависание; для остановки используйте Shift+F5.
- Хранилище API учебное и находится в памяти: новые товары пропадают после перезапуска API.
- Не распаковывайте архив внутрь нескольких вложенных папок. Рекомендуемый путь — C:\Shop5.
